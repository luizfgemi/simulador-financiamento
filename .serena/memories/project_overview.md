# Visão Geral do Projeto - Simulador de Financiamento de Veículos

## Propósito do Projeto
Este é um simulador de financiamento de veículos totalmente client-side, desenvolvido para calcular e visualizar diferentes cenários de financiamento automotivo. O projeto oferece cálculos precisos, comparações entre sistemas de amortização e visualizações interativas.

## Principais Funcionalidades
- **Cálculo Price**: Parcelas fixas com juros decrescentes
- **Sistema SAC**: Amortização constante (comparativo)
- **Taxa Anual Equivalente (TAE)**: Conversão de taxa mensal para anual
- **Gráficos interativos**: Composição das parcelas e evolução do saldo
- **Tabelas detalhadas**: Evolução mês a mês do financiamento
- **Exportação CSV**: Download da tabela de evolução
- **Custo Real do Financiamento**: Considera inflação estimada
- **Valor Presente Líquido (VPL)**: Análise de viabilidade financeira
- **Simulação de Quitação Antecipada**: Cálculo de economia

## Arquitetura
- **Frontend Only**: Aplicação 100% client-side
- **Sem Backend**: Todos os cálculos são realizados no navegador
- **Responsivo**: Interface adaptável para dispositivos móveis e desktop
